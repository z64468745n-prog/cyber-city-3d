# CYBER CITY 3D

A browser-based cyberpunk city exploration prototype built with React, Three.js, React Three Fiber and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Controls

- **WASD / arrow keys:** move
- **Mouse:** look around in first-person (click the scene to capture the pointer)
- **Shift:** sprint
- **V:** switch between first- and third-person
- **Escape:** release the mouse
- **Mobile:** use the on-screen directional pad

The city is procedurally generated. This is an initial playable prototype; it does not yet contain real building interiors, multiplayer, or advanced collision detection.
